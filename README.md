# ZarCode v1.0 (Hybrid Edition)

**ZarCode** adalah bahasa pemrograman eksperimental buatan **Anjar Irawan**  
yang memadukan sintaks bahasa Indonesia dan JavaScript agar mudah dipahami pemula.

## 🧠 Contoh Kode
```zar
fungsi mulai() {
  jk (true) {
    tampil("Halo Dunia dari ZarCode 🚀");
  }
}
mulai();
```

## ⚙️ Cara Menjalankan
1. Unduh semua file dan letakkan di satu folder.
2. Buka `index.html` di browser.
3. Tulis atau ubah kode ZarCode di textarea, lalu klik **Jalankan**.

## 🔍 File Utama
- `zarcode.js` — interpreter utama
- `example.zar` — contoh kode ZarCode
- `index.html` — halaman demo
- `README.md` — dokumentasi
